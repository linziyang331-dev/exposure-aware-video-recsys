# 长尾优化与结果范围

2026-10-30发布整理；算法实验于2026-10-29完成。代码与聚合证据已包含在v0.2.0，默认冻结基准仍为原双塔V2＋DIN V2。

## 改了什么

- 仅用标准训练点击构造共现邻域共享视频表示，历史采用同一编码；保留独立视频向量与点积检索。
- 事件风险与有点击视频均匀风险做单调混合；另做训练内频次logit调整。最终选中模型为graph_adjust10：32维、32邻居、图残差0.5、tau0.1、rho0，没有采用混合权重配置。
- 长尾R20/R100设实际增益门槛，并约束总体/头部保留；20配置验证、两个候选三种子后选择新教师，重新生成自己的Top100并适配DIN。

## 主种子标准测试

| 指标 | 原链路 | 新实验链路 |
|---|---:|---:|
| 最终Recall@20 | 13.4482% | 14.1840% |
| 最终NDCG@20 | 0.054840 | 0.057311 |
| 长尾Recall@100 | 5.3507% | 8.5168% |
| 最终长尾Recall@20 | 1.5914% | 2.3565% |

相同75,430条正事件多命中555条，其中长尾多138条。新候选池内DIN继续将裸召回R20由10.7557%提高至14.1840%，没有目标注入。

三个精排种子标准R20均正增益，但共享各自冻结召回seed42，不是三条独立完整链路。随机测试总体R20均值0.5222%→0.5023%有退化，长尾R20均值0.01284%→0.02368%有提升；仍不能称全来源升级或长尾彻底解决。
