# 数据与评测协议

数据为 [KuaiRand-Pure](https://kuairand.com/)，官方托管于 [Zenodo 10439422](https://zenodo.org/records/10439422)。下载器固定 Pure 压缩包，核对大小与 MD5 `0820331067a3784d9691136f772b35a7`，限制解压成员、路径与体积，并保存解压 SHA-256。目标为 D 盘项目 `data/raw/kuairand_pure/`。

原始 2,622,668 条记录精确去重后保留 2,600,671 条。只使用标准训练期拟合词表和热门度，已知视频目录 7,538 项。标签为 `is_click`，不是观看时长或 CTR 的替代指标。具体日历边界见 [data.yaml](../configs/data.yaml)。

| 分区（北京时间） | 时间范围 | 曝光数 |
| --- | --- | ---: |
| standard/train | 2022-04-08 至 2022-04-22，不含右端 | 1,125,689 |
| standard/validation | 2022-04-22 至 2022-04-29，不含右端 | 122,315 |
| standard/test | 2022-04-29 至 2022-05-09，不含右端 | 166,618 |
| random/validation | 同验证边界 | 288,622 |
| random/test | 同测试边界 | 897,427 |

历史只使用严格早于当前事件的标准正反馈，最长 50；同毫秒反馈延后更新，随机来源反馈不更新历史。较早验证/测试标准反馈可用于更晚查询的滚动历史，模型参数不更新。保留冷用户、冷视频与空历史。整月视频统计、时间不明的用户快照与当前反馈不进入模型特征。

Top20 指标按全部正事件计数，每事件一个相关目标；允许重复推荐，训练词表外目标计为未命中。完整目录与固定 Top100 评测分开；全目录 MRR 和池内 MRR@100 不混用。

Pure 删除了候选池外交互，不能据此恢复完整真实状态转移。随机来源标记、0.37% 替换比例或目录倒数都不能替代逐事件曝光概率。本项目的真实数据分析限定来源/分组/校准与日志排序诊断；因果 OPE 和 CQL 收益限定合成环境。

本机历史下载记录的 Zenodo 元数据许可记为 CC BY 4.0，实际 Pure 压缩包 LICENSE 为 CC BY-SA 4.0；未把两种标注强行统一。请从官方来源取得数据并自行核对适用条款。仓库不重新分发原始/处理后记录、用户/视频词表、逐事件候选、预测或权重。项目 MIT 许可不覆盖数据。详见 [历史数据审计](../reports/data_audit.md)。
