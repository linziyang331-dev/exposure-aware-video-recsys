完整测试覆盖新增长尾召回、图传播、选模、教师适配和历史模块。测试及CPU演示只证明覆盖的流程、数学和边界，不代替正式预算效果复现。算法阶段历史数值和核验范围见[长尾说明](longtail.md)与其聚合报告；历史PASS不等于公开克隆已恢复未分发资产。

发布时对最终目录、相邻ZIP和Git暂存内容逐文件核对SHA-256，暂存集合必须等于清单加`release_manifest.json`。所有源码在测试后保持字节一致，仅补充本验证文档。实际文件数量、体积和哈希见生成的清单。

本次未验证新机器安装、完整历史资产重建、线上部署或线上收益。算法独立审查在终态验证前因额度中止，终态由主助手复核，不能称完整独立审查通过。
